# Change log

This file summarizes public releases. Git history keeps the complete record of
issues, reviewed pull requests, commits, and earlier versions.

## Unreleased

- Selected GitHub Free and Pages as the primary public hosting service, with
  `main` as the deployment branch and the Pages URL as the metadata default.
- Published a current Delaware Open Data metadata inventory: 347 portal assets,
  including 177 datasets, checked October 21, 2026.
- Added searchable publisher metadata and five official MHC transition links
  with current column definitions; original MHC dictionary remains unacquired.
- Added reproducible bounded metadata refresh, immutable metadata snapshots,
  hashes, and change manifests without downloading dataset rows.
- Prepared the static public site for GitHub Pages and public Sites access.

- Added a provider-neutral prompt guide library with ten copy-and-paste
  workflows, local filtering, versioned metadata, and explicit human-review
  checkpoints.
- Added a plain-language form for proposing prompt guide improvements.
- Expanded the About page with separate Community and Technical explanations of
  the project's purpose, creation process, GitHub, provenance, preservation,
  human review, and current phase limits.
- Added Community and Technical presentation modes over the same catalog data.
- Added source-specific, plain-language GitHub reporting paths.
- Added guided forms for corrections, broken sources, variable or metadata
  feedback, and new source suggestions.

## 0.1.0 — 2026-08-17

- Published the Phase 0/1 catalog, governance, validation, monitoring, and site
  foundations.
- Imported 37 unverified source records from the Delaware SHIP Community Data
  Resource Guide with workbook provenance.
